# 任务认证与隔离 Implementation Plan

> **For agentic workers:** Use the repository's applicable implementation workflow and verify each checked step against tests and data.

**Goal:** 注册/登录，并保证每条任务操作按登录用户隔离。

**Architecture:** Alembic 新迁移增加 users 和 tasks.owner_id。独立认证模块负责密码哈希与 JWT；API 通过依赖注入 user_id，Service 和 Repository 对所有任务操作传递/使用它。

**Tech Stack:** FastAPI、SQLAlchemy 2、Alembic、pwdlib Argon2、PyJWT、pytest。

## Global Constraints

- 旧任务数据保留，owner_id 为 NULL，不自动归入新用户。
- 不接收客户端提供的 owner_id；跨用户的单条任务接口返回 404。
- 使用专用 `study_tasks_test` 执行 PostgreSQL 集成测试，不清理业务库数据。
